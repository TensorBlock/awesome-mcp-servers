## 🏠 Real Estate & Home Services

Servers for real estate data, home services, property operations, cleaning, housing workflows, or related booking and advisory tasks.

- [SENTINEL Washington Real Estate](https://github.com/cheadlee10/sentinel-mcp): Source-dated Washington property evidence and deterministic transaction math for software and AI assistants. Fourteen tools cover supported county records, permits, site and local context, market snapshots, REET, seller scenarios, offer comparisons, payments, deadlines, and evidence packets. Three calculators work without an account. Streamable HTTP endpoint: `https://app.sentineliq.net/api/v1/mcp/public`; keyed endpoint: `https://app.sentineliq.net/api/v1/mcp`. MIT companion examples; hosted service terms apply.
- [AstraNL](https://github.com/astranl/astranl-mcp): Lets an agent verify physical reality before promising it - Dutch/UK company registries (KvK, Companies House), vehicle records (RDW, DVSA), 860k+ merchant SKUs with live prices - and coordinate real-world work with other companies' agents through a cross-company Meeting Hall. Signed responses; no custody of funds; 1% coordination fee. Install: remote MCP at `https://astranl.com/mcp/sse`.
- [Zillapi Zillow Property Data](https://github.com/ZeroPointRepo/zillow-skills): Zillow property data MCP server with 4 tools for address lookup, ZPID lookup, Zestimate retrieval, and active listing search. Returns Zestimates, rent estimates, tax records, listing details, price history, school data, photos, and 300+ property fields. Streamable HTTP endpoint: https://api.zillapi.com/mcp. OAuth 2.1 with PKCE. MIT-0.
- [GetColby/claw-cleaning](https://github.com/GetColby/claw-cleaning): Remote Streamable HTTP MCP server for AI-booked apartment cleaning in San Francisco. Books weekend cleanings end-to-end, priced at $40/hour, with 3 tools for quoting and scheduling. Endpoint: `https://claw.cleaning/mcp`. No auth. MIT.
- [USDV Capital Real Estate CFO](https://smithery.ai/servers/usdv-capital/real-estate-cfo): Real estate market intelligence, financial calculators, and capital advisory MCP covering all 50 US states plus DC and Puerto Rico. 23 tools for market search, location statistics, comparisons, DSCR-style calculators, eligibility checks, and advisory workflows. Smithery install: `npx -y smithery mcp add usdv-capital/real-estate-cfo`; direct endpoint: `https://real-estate-cfo--usdv-capital.run.tools`.
- [Staying API — Airbnb Stay Data](https://github.com/nikhonit/airbnb-skills): Airbnb stay-data MCP server — look up any listing's photos, reviews, host, amenities, pricing, and 12-month availability by ID/URL/address, or search by location, dates, price, and capacity. Streamable HTTP endpoint: https://api.stayingapi.com/mcp. Free 100-credit tier. MIT-0.
- [OpenTakeoff](https://github.com/Kentucky-ai/opentakeoff): Open-source (Apache-2.0) construction takeoff MCP server — load a plan PDF, read the title block, adopt the drawing scale (never applied silently), one-click trace rooms, and export real-world quantities (square footage, linear feet, counts) with provenance receipts on every measurement. Stdio transport. Install: `npx -y opentakeoff-mcp`.
- [whodoicallfor](https://github.com/woodydaniel/whodoicallfor-mcp): Routes US home, car, and civic emergencies to the right responder — who to call, in what order, first steps, and typical costs carrying dated sources across 43 covered situations. 3 tools: `route_emergency`, `get_scenario`, `list_scenarios`. Any sponsored pay-per-call dispatch number is flagged `"sponsored": true`; life-safety numbers (911, poison control, gas utility) are never sponsored. Streamable HTTP endpoint: `https://whodoicallfor.com/api/mcp/` (trailing slash required). No auth. MIT. Docs: https://whodoicallfor.com/for-agents/.
- [Lamdis Exchange](https://github.com/lamdis-ai/lamdis-protocol): Pay a person nearby to check something or do something in the physical world, proved with a photo; free sandbox, no account needed. Remote Streamable HTTP endpoint: `https://exchange.lamdis.ai/mcp`. No auth for the eight guest tools (`check_feasible`, `observe_world`, `do_in_world`, `find_out`, `job_status`, `job_receipt`, `job_evidence`, `list_bids`); optional `Authorization: Bearer lam_sk_...` agent key for the full buyer side. Official MCP Registry id `ai.lamdis/exchange`. Docs: https://exchange.lamdis.ai/docs. Install: nothing to install, add the URL.
- [Prism](https://prism.parad1gm.com/agents): Reads leases, mortgages, insurance policies and HOA documents and returns every deadline with its date, the consequence of missing it, and the source sentence. 8 tools including `prism_review_contract`, `prism_get_contract` and `prism_upcoming_deadlines`. Streamable HTTP endpoint: `https://prism.parad1gm.com/api/prism-mcp`. OAuth 2.1 or API key. $0.50 per contract, 3 free. Official MCP Registry id `com.parad1gm/prism`. Hosted; closed source.
- [CoworkingView](https://coworkingview.com/en/mcp): Independent index of coworking spaces and private offices across 62 cities in Europe and the Gulf. 10 tools cover location and filter discovery, free-text query resolution, space search, single-space detail, side-by-side comparison of up to five spaces, aggregated market rates per workspace type, a best-value city ranking, operator profiles and editorial place guides. Prices are the rates operators publish themselves, and the price index is CC BY 4.0. Remote Streamable HTTP endpoint: `https://mcp.coworkingview.com/mcp`. No auth, read-only. OpenAPI for the companion REST API: https://coworkingview.com/openapi.json.
- [Zornade MCP](https://github.com/zornade/zornade-mcp): Italian cadastral, geospatial and real-estate data for AI agents: geocoding on 18.7M+ addresses, parcel profiles (risk, solar potential, valuations), parcel lookup by point/bbox and administrative lists. Remote: https://mcp.zornade.com/mcp (free Zornade API key). Self-host via Docker in the repo.
- [Pillr](https://pillr.fr/mcp): French property data: price per m² by municipality, local market summary and planning permit requirements. 3 tools, all read-only: price per m² of a French municipality from notarial sales (DVF, 2021 to 2025), market summary of a municipality, and the planning formality required for a works project. Remote Streamable HTTP endpoint: `https://pillr.fr/api/mcp`. Free, no account, no auth, limited to 60 calls per hour. Official MCP Registry id `io.github.maixmeduret/pillr`. Hosted; no public source repository. Install: nothing to install, add the URL.
