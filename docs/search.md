Two tools: `search_news` (keywords, language, country, source domain and quality rank, sentiment range, entity IDs, media, date ranges, sorting, faceting, highlighting) and `suggest`, which resolves a name like "Tesla" into the entity, category, topic and industry IDs the precise filters need. Install: `npx -y australian-law-mcp`. Transport: stdio. Auth: none, no API key and no sign-up. License: MIT. Docs URL: https://github.com/ChangkeunJ/australian-law-mcp.
