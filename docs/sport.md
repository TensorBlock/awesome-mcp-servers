## ⚽ Sports

Servers providing access to sports-related APIs and analysis.

- [GymFlexa](https://github.com/gymflexa/claude-plugin): Read owned gym configuration, capacity, service catalogs, aggregate schedules and recorded-payment summaries without member records. Hosted Streamable HTTP at `https://mcp.gymflexa.com/mcp`; OAuth account authorization required. [Docs](https://www.gymflexa.com/developers/#mcp). Public connector configuration and workflow skills: Apache-2.0.

- [krmisystems/fantasy-football-manager](https://github.com/krmisystems/fantasy-football-manager): Snake-draft simulations, lineup and waiver analysis, and controlled ESPN actions with approval modes and per-team limits. Install: `uvx fantasy-football-manager` (Python 3.11+). Transport: stdio. Auth: none for imported or synthetic data; ESPN sign-in for live operation. Clients: Codex and other MCP clients. Docs: [Setup](https://github.com/krmisystems/fantasy-football-manager/blob/main/docs/PLUGIN_INSTALL.md). License: MIT.

- [dhrbtjr0331/nba-stats-predictor-mcp](https://github.com/dhrbtjr0331/nba-stats-predictor-mcp): Generates NBA player performance forecasts using real-time data analysis and advanced statistical modeling.
- [JamsusMaximus/trainingpeaks-mcp](https://github.com/JamsusMaximus/trainingpeaks-mcp): Accesses TrainingPeaks training data including fitness metrics (CTL/ATL/TSB), workout history, and power/pace personal records for endurance athletes.
- [henryco23/NBA](https://github.com/henryco23/NBA): A Python server utilizing MCP to provide comprehensive access to NBA statistics and live game data through the NBA API.
- [yeonupark/mcp-soccer-data](https://github.com/yeonupark/mcp-soccer-data): Delivers real-time football match data through natural language interactions using the SoccerDataAPI.
- [guillochon/mlb-api-mcp](https://github.com/guillochon/mlb-api-mcp): A Python MCP server that acts as a proxy to the freely available MLB API, which provides player info, stats, and game information.
- [seang1121/sports-betting-mcp](https://github.com/seang1121/sports-betting-mcp): AI-powered sports betting intelligence for NBA, NHL, and NCAAB. Provides live odds, injury reports, line movement, daily picks with confidence scores, and visual bet slip cards — backed by 1,353+ resolved picks with 59.6% documented win rate.
- [livetennisapi/livetennisapi-mcp](https://github.com/livetennisapi/livetennisapi-mcp): Real-time tennis scores, players, fixtures and model win-probability across ATP, WTA, Challenger and ITF, plus match-winner market prices. 12 read-only tools, tier-aware so a plan wall returns a plain-English explanation instead of a bare 403. Hosted Streamable HTTP endpoint: `https://mcp.livetennisapi.com/mcp`, or `npx livetennisapi-mcp` for stdio, both with `LIVETENNISAPI_KEY`; free tier available (no card). MIT.
- [JacobiusMakes/parlay-api-mcp](https://github.com/JacobiusMakes/parlay-api-mcp): Sports odds and player props for private research using your own API key, with free monthly credits and paid plans. Coverage varies by sport, bookmaker, market, and date. Install: `uvx parlayapi-mcp`; transport: stdio; set `PARLAYAPI_KEY` for account data. MIT.
- [esinesmen-lab/skormerkez-mcp](https://github.com/esinesmen-lab/skormerkez-mcp): Live football scores, fixtures, league tables and verified match reports from SkorMerkez (Turkey-first, ad-free, no betting data). Remote endpoint: https://skormerkez.com/mcp — no install, no auth.
- [wmmg101/kilter-mcp](https://github.com/wmmg101/kilter-mcp): Read-only access to your own Kilter Board climbing logbook: sessions, sends, projects, grade pyramid, hardest sends, progression and wall-angle comparison. Unofficial. Install: `uvx kilter-mcp`. Transport: stdio. Auth: Kilter account credentials via KILTER_USERNAME / KILTER_PASSWORD env vars. Clients: Kiro, Claude Desktop, Claude Code, Codex, Cursor, VS Code, Windsurf, Gemini CLI, Zed. Docs: https://github.com/wmmg101/kilter-mcp#readme. License: MIT. Registry: io.github.wmmg101/kilter-mcp.
- [odds-api/odds-api](https://github.com/odds-api/odds-api): OpenAPI-first sports odds MCP server with 32 tools for live and historical bookmaker odds, results, line movement, arbitrage, positive EV, racing, and streaming metadata. Install: `npx @odds-api/mcp`. Transport: stdio. Auth: `ODDS_API_KEY`; local mock mode is keyless. Clients: Claude, Cursor, Windsurf, Cline, Codex, and other MCP clients. Docs: https://github.com/odds-api/odds-api/tree/main/mcp-server. License: Apache-2.0.
- [bvatech/povver-mcp](https://github.com/bvatech/povver-mcp): Read and write access to your own Povver strength-training data from an AI assistant: set-level workout history, per-lift trends, muscle volume, routines and plans. Hosted remote server, no install. Transport: Streamable HTTP at `https://mcp.povver.ai/mcp`. Auth: OAuth 2.1. Requires a Povver subscription (iOS app, 14-day free trial, then EUR 9.99/month or EUR 79.99/year). The server source is closed. The repo holds the README and server.json. Registry: ai.povver/mcp-server.
- [jameselle/sockodds-mcp](https://github.com/jameselle/sockodds-mcp): Australian bookmaker odds from the SockOdds API (https://sockodds.com): find an event from a plain question, then get prices by bookmaker, the best price per side and no-vig fair odds. Tools: list_leagues, find_event, get_odds, best_price, fair_odds. Install: `npx -y sockodds-mcp` (Node.js 20+). Transport: stdio. Auth: `SOCKODDS_API_KEY` (free key, covers AFL, NRL, NFL and MLB); `SOCKODDS_DEMO=1` runs on invented sample data with no key. Clients: Claude Code, Claude Desktop and other MCP clients. Docs: https://github.com/jameselle/sockodds-mcp#readme. License: MIT. Registry: io.github.jameselle/sockodds-mcp.
- [jameselle/betbank-mcp](https://github.com/jameselle/betbank-mcp): Australian sports betting analytics from your own BetBank.ai account: bookmaker odds compared for a match, arbitrage and middles, +EV picks, price moves, ladders and player form, bookmaker promotions, and your own tracked bets, results and price alerts. Read-only apart from your own price alerts; it never places a bet. Hosted remote server, no install. Transport: Streamable HTTP at `https://betbank.ai/api/mcp`. Auth: OAuth 2.1 with PKCE (dynamic client registration). Requires a BetBank Gold membership (https://betbank.ai/pricing). The server source is closed. The repo holds the README and server.json. 18+. Clients: Claude, Claude Code, Cursor, VS Code and other remote-capable MCP clients. Docs: https://github.com/jameselle/betbank-mcp#readme. Registry: io.github.jameselle/betbank-mcp.
- [fitlog-mcp](https://github.com/hahahahahahahahah6/fitlog-mcp): Self-hosted MCP server giving Alexa+ a memory for your training — log sets by voice, check personal records, get workout plans and protein targets. Python, stdlib-only, MIT.
- [Realtime Sports API](https://github.com/ElcoDevRepos/realtime-sports-api-examples): Live scores, schedules, play-by-play, box scores, teams, rosters, athletes, injuries, news, and single-source betting odds for NFL, college football, NBA, men's college basketball, MLB, NHL, and 23 soccer competitions. Fourteen read-only tools cover leagues, events, plays, box scores, odds, schedules, standings, teams, rosters, athletes, injuries, and news. Hosted Streamable HTTP endpoint: `https://www.realtimesportsapi.com/api/mcp`; initialization and tool discovery are public, while tool calls require an API key as a Bearer token. [Docs](https://www.realtimesportsapi.com/docs/mcp).
- [Ball Ranks](https://ballranks.com/): Read-only NFL and NBA fantasy rankings and player projections, including weekly, season, and player rankings. Hosted Streamable HTTP endpoint: `https://ballranks.com/api/mcp`; no authentication is required for the free V0 data. Proprietary hosted service.
