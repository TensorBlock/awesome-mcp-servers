Adds **srezai** — a remote MCP server for web search, page reading and structured extraction.

- 12 tools: `web_search`, `image_search`, `read_url`, `read_urls`, `fetch_page`, `extract`, `verify_claim`, `answer_search`, `deep_research`, `map`, `crawl`, `get_usage`
- Remote endpoint: https://srezai.ru/api/mcp (Streamable HTTP, `Authorization: Bearer <API key>`), keys and a free balance check via https://srezai.ru/dashboard
- Strong Russian-web coverage, pages returned as clean Markdown, JavaScript rendered on our side
- Pay per result instead of a subscription; `get_usage` is free
- Source (MIT stdio bridge): https://github.com/srezai-team/srezai-mcp-web-search — docs: https://srezai.ru/docs/mcp
- Category: Search (also fits Browser Automation & Web Scraping)

Русский: веб-поиск, чтение страниц в Markdown, карта сайта и обход разделов, извлечение данных по JSON-схеме и проверка утверждений с цитатами — 12 инструментов для ИИ-агентов, сильное покрытие рунета.
